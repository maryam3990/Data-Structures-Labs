# Lab 2 - Doubly Linked List

## Overview
This lab focuses on the implementation of a generic Doubly Linked List in C++.

The list maintains both `head` and `tail` pointers and allows traversal and manipulation of nodes in both directions.

## Concepts Covered
- Doubly Linked Lists
- Dynamic Memory Allocation
- Templates
- Forward and Backward Traversal
- Pointer Manipulation
- Searching
- Sorting
- List Reversal
- Merging Lists
- Duplicate Removal

## Implemented Operations
- Insert at the start
- Insert at the end
- Insert at a specific position
- Remove from the head
- Remove from the tail
- Remove a specified value
- Traverse the list forward
- Traverse the list backward
- Find the position of an element
- Count the total number of nodes
- Display information about the current node
- Find the middle node using slow and fast pointers
- Insert an element in sorted order
- Reverse the linked list
- Remove duplicate values
- Merge two sorted doubly linked lists
- Find the union of two lists
- Find the last occurrence of an element
- Sort the list using Selection Sort
- Properly deallocate memory using a destructor

## Time Complexity
Some important operations include:

- Insert at start: `O(1)`
- Insert at end: `O(1)`
- Remove from head: `O(1)`
- Remove from tail: `O(1)`
- Search: `O(n)`
- Traversal: `O(n)`
- Reverse list: `O(n)`
- Merge two sorted lists: `O(n + m)`
- Selection Sort: `O(n²)`
