# Lab 1 - Singly Linked List

## Overview
This lab focuses on the implementation and manipulation of a generic Singly Linked List in C++ using templates.

The linked list is implemented using a nested `Node` class and supports several basic and advanced linked list operations.

## Concepts Covered
- Singly Linked Lists
- Dynamic Memory Allocation
- Templates
- Node Traversal
- Searching
- Insertion
- Deletion
- Duplicate Removal
- Merging Sorted Lists

## Implemented Operations
- Insert a node at the start
- Insert a node at the end
- Insert a node before a specified value
- Search for an element
- Check whether the list is empty
- Display the linked list
- Remove duplicate values
- Delete elements within a specified range
- Merge two sorted linked lists
- Properly deallocate nodes using a destructor

## File
- `Lab_1.cpp`

## Language
C++

## Purpose
The purpose of this lab is to understand the internal working of singly linked lists and practice pointer manipulation, dynamic memory management, and common linked list algorithms.
